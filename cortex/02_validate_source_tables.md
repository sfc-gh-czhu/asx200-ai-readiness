# Validate ASX 200 source tables before ontology-stack-builder

Schema: AI_READINESS_DB.ASX200

Run and summarize:

```sql
SELECT 'COMPANY' AS t, COUNT(*) AS n FROM AI_READINESS_DB.ASX200.COMPANY
UNION ALL SELECT 'RAW_DOCUMENT', COUNT(*) FROM AI_READINESS_DB.ASX200.RAW_DOCUMENT
UNION ALL SELECT 'POLICY', COUNT(*) FROM AI_READINESS_DB.ASX200.POLICY
UNION ALL SELECT 'BUYER', COUNT(*) FROM AI_READINESS_DB.ASX200.BUYER
UNION ALL SELECT 'GTM_OPPORTUNITY', COUNT(*) FROM AI_READINESS_DB.ASX200.GTM_OPPORTUNITY
UNION ALL SELECT 'COMPANY_AI_PROFILE', COUNT(*) FROM AI_READINESS_DB.ASX200.COMPANY_AI_PROFILE;
```

Also report:
- COUNT(DISTINCT COMPANY_ID) in COMPANY (expect ~200)
- POSTURE distribution in POLICY (permissive vs governed vs unknown)
- DEVELOPER_DENSITY_TIER distribution in HIRING_SIGNAL or COMPANY_AI_PROFILE
- COUNT of BUYER where IS_ENTRY_POINT = TRUE

Flag any table with zero rows that blocks ontology design. Recommend whether to proceed to ontology-stack-builder Phase 1.
